# Les 120 images WebP de la page d’accueil PEMESA

Les fichiers `frame_0001.webp` à `frame_0120.webp` sont présents dans ce dossier. Ils sont publiés par le workflow `.github/workflows/create-home-frames.yml`.

- Format : WebP, **1280 × 720**, fond `#dcd0c8`.
- Ordre : portrait → transition filaire → faisceaux lumineux → anneau.
- Utilisation : `home-scroll.js` relie les 120 fichiers à ScrollTrigger sur la seule page d’accueil.
- Régénération : `scripts/build_home_frames.py` (entrée vidéo facultative, effet abstrait de secours si indisponible).
- La vidéo ayant servi de référence est filmée sur un écran : ce montage est recadré et ne constitue pas la séquence 3D originale en qualité native.
- Avant un usage commercial, vérifiez que vous disposez des droits nécessaires pour réutiliser les images de la vidéo de référence.

Ne pas utiliser ces visuels comme des mesures de santé réelles ; ils sont uniquement décoratifs.
