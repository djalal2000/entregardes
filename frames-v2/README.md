# PEMESA — Séquence cinématique v2

Les images `frame_0001.webp` à `frame_0120.webp` sont produites à partir des 5 images clés situées dans `assets/keyframes` par `scripts/build_cinematic_v2.py`.

Tant que les 120 images ne sont pas publiées, `home-scroll.js` affiche une illustration de secours, plutôt que l’ancienne séquence insatisfaisante.

La page d’accueil utilise Canvas + GSAP ScrollTrigger + Lenis et `#dcd0c8`. Les espaces privés ne sont pas affectés.
